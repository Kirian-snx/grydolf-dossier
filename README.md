# Grydolf Dossier

Site statique hébergeant le dossier d'investigation fictif sur **CMDR Grydolf** — personnage de l'univers Elite Dangerous. Rédigé du point de vue d'un journal galactique satirique, *News Galactique*.

Le contenu évolue après chaque session de jeu.

## Stack

HTML + CSS vanilla — zéro framework, zéro build step. Déploiement automatique sur Vercel à chaque push.

## Structure

```
index.html    — page principale
style.css     — système de design complet
images/       — captures de jeu et assets visuels
```

## Mise à jour du contenu

Éditer `index.html` directement. Pour ajouter une image, encoder en base64 ou déposer dans `images/` et référencer avec un chemin relatif.
